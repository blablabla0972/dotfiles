## Changes

- Desktop toggle: preserve pipe/newline characters in workspace and scratchpad
  names; retain support for state written by the previous version.
- Theme owner: cleanup errors cannot overwrite a verified apply/rollback result;
  GTK/Qt INI writes preserve symlinks; malformed expiring markers are ignored.
- Matugen: reject nonempty template hooks before rendering because their writes
  have no snapshot/rollback coverage. The tracked configuration has no hooks.
- Picker: encode local file URLs, decode literal image filenames through stdin,
  regenerate empty thumbnails, and report directory enumeration failures.
- Installer: replace repeated basename/dirname subprocesses with Bash expansion.
  Nine interleaved dry-run samples: median 79.95 ms → 9.68 ms; four selector modes
  produced identical output. This measures dry-run elapsed time, not installation.
- Fish: initialize Starship only in interactive shells (probe: noninteractive
  invocations 1 → 0; interactive remains 1).
- Installer tests: stub systemctl so `--all` tests cannot reload the host manager.
